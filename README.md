# PocketSmart AI

## Your Smart Budget & Recommendation Assistant

PocketSmart AI is a GenAI-powered budget planning and recommendation system.

### Features

- 🏠 Home Decor Planner
- 🎉 Party Planner
- 💎 Jewelry Planner
- 🔐 User Registration and Login
- 💰 Budget-based recommendations
- 🤖 AI-powered recommendation support
- 📱 Responsive web interface

### Technologies Used

- HTML
- CSS
- JavaScript
- SQLite
- Google Gemini API
